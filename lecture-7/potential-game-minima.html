Global, Local, and Directional-Local Minima of φ(γ₁, γ₂)

Choose an example below. Each one is marked with the exact definitions from lecture: a global minimum beats every point in the domain; a local minimum beats every nearby point in every direction; a directionally-local minimum (a Nash equilibrium of the potential game) only has to beat points reachable by moving one coordinate at a time — so it can fail to be a true local minimum if a simultaneous, diagonal move does better.

Global minimum
φ(γ*) ≤ φ(γ) for all γ in the domain.
Local minimum
beats every neighboring point, including diagonal moves — a true minimum in the usual multivariable sense.
Directional-local only
beats every neighbor along the γ₁ and γ₂ axes alone, but not diagonally — a Nash equilibrium that is not a true local minimum.
